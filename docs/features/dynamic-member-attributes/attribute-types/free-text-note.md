# Attribute type: Free Text Note

| Field | Value |
|---|---|
| Key | `free_text_note` |
| Name | Free Text Note |
| Description | A short freeform note you can attach to a member for general remarks or context. Accepts any text up to 1000 characters, and can be left blank. |

## Validation rules

- Maximum length: **1000 characters**.
- No other constraints — an empty/blank value is valid.
