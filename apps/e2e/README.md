# apps/e2e — End-to-end behaviour tests

Runs the Gherkin scenarios in [`../../docs/testing/features`](../../docs/testing/features)
as Playwright tests via [`playwright-bdd`](https://vitalets.github.io/playwright-bdd/).

```bash
vp run test          # build contract → bddgen → playwright test
vp run test:headed   # watch it in a browser
vp run report        # open the last HTML report
```

## Layout

| Path                     | What it is                                                     |
| ------------------------ | -------------------------------------------------------------- |
| `playwright.config.ts`   | Playwright config; points `bddgen` at `docs/testing/features`. |
| `fixtures.ts`            | Extends the BDD `test` with the per-scenario `world` fixture.  |
| `steps/`                 | Step definitions, grouped by feature.                          |
| `support/members-api.ts` | REST helper used to arrange and clean up member data.          |
| `.features-gen/`         | Generated by `bddgen`; never edit, never commit.               |

The `webServer` block starts the API (`apps/api`) and the website
(`apps/website`) automatically. `vp run test` builds `api-contract` first, so
both servers resolve its `dist/`.

See [`docs/testing/README.md`](../../docs/testing/README.md) for the strategy,
the coverage guardrail, and how to add a scenario.
